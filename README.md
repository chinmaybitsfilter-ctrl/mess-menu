# mess-menu

Unofficial BITS Pilani mess menu app. Open: https://chinmaybitsfilter-ctrl.github.io/mess-menu/

- Updates itself every day at 05:45 IST (GitHub Actions reads ssms-pilani.in)
- Weekly PDF: https://chinmaybitsfilter-ctrl.github.io/mess-menu/menu.pdf
- Add to your phone's home screen to use it like an app.

Data source: ssms-pilani.in (SSMS, BITS Pilani). Not affiliated with SSMS.
